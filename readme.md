# 高美惠 (Mei-Hui Kao) 個人數位名片網頁

這是一個為高美惠量身打造的輕量級、具備高度視覺吸引力的個人數位名片網頁。採用時下流行的**毛玻璃（Glassmorphism）**風格，搭配充滿活力的動態漸層背景與色彩繽紛的技能標籤，非常適合用於個人社群連結導流或是簡歷展示。

## 🎨 網頁特色 (Features)

* **亮麗視覺風格**：採用動態漸層背景（Animated Gradient）與裝飾性光暈，營造活潑、年輕的氛圍。
* **毛玻璃懸浮卡片**：主體採用半透明的毛玻璃質感（Backdrop-blur），使畫面更具層次感。
* **專屬照片光環**：預留了個人大頭照的位置，並在外圍加上了會緩慢旋轉的漸層光環動畫。
* **互動式社群按鈕**：底部的聯絡圖示帶有平滑的懸浮動畫，當游標停留在 Line 圖示上時，會貼心地自動浮現 Line ID 提示（Tooltip）。
* **完全響應式 (RWD)**：無論在手機或電腦螢幕上，這張「數位名片」都能完美置中呈現。

## 🛠️ 使用技術 (Tech Stack)

* **HTML5**：網頁基礎結構。
* **Tailwind CSS (CDN)**：使用 Utility-first CSS 框架快速打造客製化樣式，包含漸層與動畫設定。
* **Google Fonts**：引入 `Noto Sans TC` (思源黑體)。
* **FontAwesome (CDN)**：提供高品質的向量圖示（如 Email、Line、Instagram 等 icon）。

## 🚀 如何使用與修改 (How to Use & Edit)

本專案無需任何安裝或編譯過程。

1. **預覽網頁**：將 `index.html` 檔案下載至您的電腦中，點擊右鍵選擇「在瀏覽器中開啟」即可預覽。
2. **替換個人照片 (重要！)**：
   * 使用任何文字編輯器（如記事本、VS Code、Sublime Text）打開 `index.html`。
   * 搜尋 `<img` 標籤（約在第 64 行附近）。
   * 將 `src="..."` 裡面的網址替換成您自己的照片網址（可以是相簿連結，或是本地端的圖片路徑，如 `src="my-photo.jpg"`）。
3. **修改文字內容**：若需要更改興趣或介紹，直接在 HTML 檔案中尋找對應的中文字進行修改並存檔即可。
